# Changelog

All notable changes to the Proof Of Day project will be documented in this file.

## [Unreleased]

## [1.1.0] - 2025-12-30

### Added
- **Gas Price Tracker**: Real-time Base network gas fees and cost estimates
- **Reward Calculator**: Interactive projection tool for potential earnings
- **Data Export**: CSV and JSON export functionality for user data
- **Premium Check-In**: Priority check-in button UI
- **Accessibility**: Keyboard navigation and focus management
- **Performance**: Loading skeletons and error boundaries

### Changed
- **UI Layout**: Moved Daily Check-In to the top of the dashboard for better UX
- **Build System**: optimized Next.js config for dynamic rendering
- **Documentation**: Updated README with developer credits

### Fixed
- Resolved Vercel build errors related to localStorage in SSG
- Fixed mobile responsiveness for leaderboard tables

## [1.0.0] - 2025-12-25

### Added
- Initial release of Proof Of Day
- Daily check-in smart contract integration
- Streak tracking and visualization
- Farcaster identity integration
- Base mainnet deployment
