# Security Policy

## Supported Versions

The following versions of the project are currently being supported with security updates.

| Version | Supported          |
| ------- | ------------------ |
| 0.1.x   | :white_check_mark: |
| < 0.1.0 | :x:                |

## Reporting a Vulnerability

We take the security of our project seriously. If you have discovered a security vulnerability, please report it to us as described below.

1.  **Do not report security vulnerabilities through public GitHub issues.**
2.  Please email `earnwithalee@gmail.com` with a detailed description of the vulnerability.
3.  We will acknowledge your report within 48 hours.
4.  We will provide a fix or a mitigation plan as soon as possible.
